This is a project to play a quiz using Python.

We store past scores and display a leadervoard of top 3 highest scores before and after you play the quiz.

To run it on your own machine:
1. Clone this repository
2. Run "pip install requirements.txt"
3. Create a file named __init__.py 
4. Run "pip mcq.py"

Note: Clear leaderboard.json before running mcq.py to remove any older scores that you wont need
